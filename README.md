# Proyecto Refugio de Animales

Este proyecto simula un refugio de animales donde se pueden registrar perros y gatos, así como voluntarios que colaboran en el refugio. También permite registrar adopciones de los animales por parte de personas interesadas.

## Funcionalidades
- Crear animales (Perro o Gato) con sus atributos específicos.
- Crear voluntarios con nombre y horas de trabajo.
- Registrar animales y voluntarios dentro del refugio.
- Listar todos los animales y voluntarios registrados.
- Registrar adopciones y mostrar qué animal fue adoptado por quién.

## Archivos del proyecto
- `Animal.h` → Clase base abstracta.
- `Perro.h`, `Gato.h` → Clases que heredan de Animal.
- `Voluntario.h` → Clase para voluntarios del refugio.
- `Adopcion.h` → Clase para registrar adopciones.
- `Refugio.h` → Clase para manejar animales y voluntarios.
- `main.cpp` → Programa principal que integra todas las clases.
